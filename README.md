<h1>This was made for hackclub Horizons</h1>
<p>I made this by myself</p>
<p>I did not use Ai</p>
<h3>The movement</h3>
<p>Movement is w for forwards s for backwards</p>
<p>a is for turn left(counterclockwise) and d is for turn right(clockwise) the arrow will show your rotation</p>
<p>Mouse click on the bell to start the game</p>
<h1></h1>
<p>The goal is to get to class in time and keep on doing that for as long as possible</p>
<p>This game is called "get to classs"</p>
<p>Issue you may see is that you may encounter a class twice</p>
<p>You can play this game on itch.io</p>
